Em Caruaru, audiência publica discute o projeto de BRT

Nesta sexta, será realizada, às 9h, uma audiência publica para debater o Projeto de Construção dos Corredores Norte/Sul e Leste/Oeste – BRT, no município de Caruaru. De autoria do vereador Marcelo Gomes (PSB), o intuito da audiência é discutir junto à sociedade o projeto de lei nº 6.692/2013 encaminhado pelo Executivo que autoriza o município a contratação do financiamento de R$ 250 milhões junto ao BNDES para implantar o sistema de mobilidade urbana na cidade. “Essa audiência promoverá o debate em torno da articulação política de transporte, trânsito e acessibilidade para proporcionar a qualificação do sistema de mobilidade urbana em Caruaru. É um momento oportuno para o diálogo com especialistas que estarão presentes para explicar as questões relacionadas com o custo-benefício, além das expectativas de inicio das obras e sobre o projeto de pavimentação que irá beneficiar milhares de caruaruenses”, ressaltou o parlamentar. ...
